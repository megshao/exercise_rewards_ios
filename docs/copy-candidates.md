# 品牌命名與介面文案候選

> 專案：協助台灣民眾參加運動部「揮汗有禮・全民動起來」運動幣加碼活動的 iOS App。
> ⚠️ **前提已變（2026-09-06）**：健康連結功能已於 v1.1 移除，以下文案中提到「讀步數／Apple 健康／健康數據」的部分**都已不適用**，

## 1. App 命名候選

| # | 中文名 | 英文 / slug | 一句定位 | 命名理由 |
|---|--------|-------------|----------|----------|
| 1 | **颯步** | Sabo / `sabo-fit` | 走得颯，領得快。 | 「颯」有俐落、爽快、有風的意象，「步」直指步數；讀音 sà-bù 轉成 Sabo 好唸好記、slug 短。與現有 repo 名一致，零轉換成本。 |
| 2 | **步步有禮** | Bubu Reward / `bubu` | 每一步都算數，走到就換得到。 | 直接呼應活動名「揮汗有禮」，「步步」口語又有累積感，長輩也秒懂；缺點是偏活動限定，日後擴充其他運動指標時較窄。 |
| 3 | **走賺** | Zouzhuan / `zouzhuan` | 走路就是在賺。 | 兩字動機強、記憶點高，適合社群傳播；但「賺」字略偏誘因導向，與「值得信任」調性需靠視覺平衡。 |
| 4 | **動幣通** | Movecoin Pass / `movecoin` | 運動幣任務一鍵通關。 | 明示「運動幣」+「通」（通關、通行），功能導向、店家與民眾一聽就懂；缺點是名稱與官方名稱過近，需避免被誤認為官方 App。 |
| 5 | **汗水通行證** | Sweat Pass / `sweatpass` | 用汗水換禮，不用重打個資。 | 「通行證」精準描述一鍵登入的價值，英文 Sweat Pass 有國際感；缺點是五個字略長，圖示文字空間吃緊。 |
| 6 | **好步** | Haobu / `haobu` | 好好走路，好禮自來。 | 「好」字親切、正向，可延伸「好步・好禮・好放心」三段式 slogan；缺點是辨識度中等，App Store 搜尋容易撞名。 |

### 推薦：颯步 Sabo

- 三個調性一次到位：「颯」= 活力清爽、「步」= 健康、極簡兩字 = 不官僚。
- 不綁死活動名稱，活動結束後仍可作為「步數換好禮」的泛用品牌。
- Sabo 在英文語境中性、無負面聯想，slug `sabo-fit` 已存在，開源 repo 與 App 名對齊，信任感一致。
- 中文副標建議固定為：**颯步 — 走得颯，領得快。**

## 5. 資安 / 隱私說明頁信任文案

**你的資料，只留在這支手機。**

颯步不架伺服器、不收集個資。你的身分資料與健康數據只儲存在你手機的本機加密空間，不上傳雲端、不同步到任何第三方，也不寫入任何 log。一鍵登入時，App 只把你已授權的資料直接送到官方「我的任務」網站，中間沒有我們的伺服器經手。

我們知道「相信我們」不夠，所以整個專案完全開源。每一行處理個資的程式碼，你或任何工程師都可以在 GitHub 上逐行檢查、稽核、回報問題。刪除 App，資料就跟著一起消失。

> 短版（「我的資料」頁一行）：本機儲存・不上雲・不寫 log・全程開源。

### 5.1 已採用版本（「我的資料」頁首，實裝文案）

> ⚠️ **1.0 校正**：個資已最小化到登入必需的**身分證號／出生日期／手機**三欄，
> 姓名、email、健保卡卡號不再收集。下方第 2、3 點提到的「以下資料」即指這三欄。

標題：**本 App 不蒐集、不外傳你的個資**

1. 本 App 沒有任何伺服器與後台，你的資料不會上傳雲端、不會同步 iCloud、不會寫入紀錄檔，也不會提供給任何第三方。
2. 以下資料只在你登入時，由這支手機直接送到官方網站 500.gov.tw，中間不經過任何其他服務。
3. 為了免除每次重新輸入，資料僅以加密方式保存在這支手機（Keychain）；你可以隨時用下方「立即清除本機資料」永久刪除。

> 用語備忘：標題只寫「不蒐集、不外傳」，**不寫「不儲存」**——本機 Keychain 確實有存，寫「不儲存」會與實作不符。
